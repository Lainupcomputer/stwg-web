2. Allgemeine Hinweise

Der Schutz deiner personenbezogenen Daten ist uns wichtig.

Personenbezogene Daten werden auf dieser Website nur verarbeitet, soweit dies für den Betrieb der Website, die Bereitstellung der Funktionen oder die Bearbeitung von Anfragen erforderlich ist.

Es werden keine personenbezogenen Daten zu Werbe-, Tracking- oder Marketingzwecken verarbeitet.

3. Aufruf der Website

Beim Aufruf dieser Website können durch den Webserver technisch notwendige Informationen verarbeitet werden.

Hierzu können insbesondere gehören:

  • IP-Adresse
  • Datum und Uhrzeit des Zugriffs
  • aufgerufene URL
  • verwendeter Browser
  • verwendetes Betriebssystem

Diese Informationen dienen insbesondere dem sicheren und technisch ordnungsgemäßen Betrieb der Website.

4. Benutzerkonto und Anmeldung

Für bestimmte Funktionen der Website ist eine Anmeldung erforderlich.

Im Rahmen der Anmeldung können personenbezogene Daten verarbeitet werden, die für die Verwaltung des Benutzerkontos erforderlich sind.

Die Verarbeitung erfolgt ausschließlich zur Bereitstellung der jeweiligen Website-Funktionen und zur Verwaltung des Benutzerkontos.

5. Session-Cookies

Diese Website verwendet technisch notwendige Session-Cookies.

Das Session-Cookie dient insbesondere dazu, eine angemeldete Sitzung einem Benutzer zuordnen und den Login-Status während der Nutzung der Website aufrechterhalten zu können.

Die eigentlichen Session-Daten werden serverseitig gespeichert. Das Cookie enthält dabei nicht die vollständigen Sitzungsdaten.

Die verwendeten Session-Cookies werden nicht für Tracking, Werbung oder Marketing verwendet.

6. Speicherdauer der Session

Die Session kann entsprechend der technischen Konfiguration der Website für einen begrenzten Zeitraum bestehen.

Nicht mehr benötigte Sitzungsdaten werden im Rahmen der technischen Verwaltung der Website gelöscht.

7. Discord-Widget

Auf der Startseite wird ein Widget des Dienstes Discord eingebunden.

Beim Laden des Widgets kann eine Verbindung zu Servern von Discord hergestellt werden.

Dabei können insbesondere technische Informationen wie die IP-Adresse und Informationen zum verwendeten Browser an Discord übertragen werden.

Das Discord-Widget wird ausschließlich zur Darstellung des offiziellen STWG-Discord-Servers verwendet.

Weitere Informationen zur Verarbeitung personenbezogener Daten durch Discord findest du in den Datenschutzinformationen von Discord.

8. Bootstrap / externe Inhalte

Auf Teilen der Website wird das CSS-Framework Bootstrap über ein externes Content Delivery Network (CDN) eingebunden.

Beim Laden dieser Ressource kann eine Verbindung zum jeweiligen CDN hergestellt werden. Dabei kann insbesondere die IP-Adresse des Besuchers übertragen werden.

Soweit möglich, sollten externe Ressourcen zukünftig lokal auf dem Server bereitgestellt werden, um externe Datenübertragungen zu vermeiden.

9. Keine Analyse- oder Marketingdienste

Auf dieser Website werden nach aktuellem Stand keine Dienste wie Google Analytics, Matomo, Meta Pixel oder vergleichbare Tracking- und Analysewerkzeuge eingesetzt.

Ebenso werden keine Marketing- oder Werbe-Cookies eingesetzt.
